# Sistema de gerenciamento de clientes
Sistema criado para o gerenciamento de clientes de uma 
escola de inglês, com front-end e back-end.


Aplicação web desenvolvida para cadastrar e consultar.
Desenvolvimento de front-end e back-end.

## Tecnologias utilizadas

- TypeScript
- Node 20
- MariaDB
- React
- Express

## Funcionalidades

- Cadastro de clientes
- Login de Clientes
- Pesquisa por e-mail
- Validação dos campos
- Tratamento de erros
